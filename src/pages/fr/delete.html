Suppression du compte et des données

Cette page concerne les demandes de suppression de compte et de données pour le jeu {{name}} (Android, développeur : {{developerName}}).

Dans le jeu (immédiat)

  1. Touchez votre avatar en haut à gauche, puis ouvrez la plaque COMPTE sur l’écran PROFIL. (PARAMÈTRES → COMPTE ET CONFIDENTIALITÉ → COMPTE GOOGLE mène au même endroit.)
  2. Touchez SUPPRIMER MON COMPTE, puis OUI, SUPPRIMER DÉFINITIVEMENT.
  3. Sélectionnez une nouvelle fois le même compte Google pour confirmer votre identité.

Votre compte et toutes les données du tableau ci-dessous sont supprimés immédiatement, et le jeu repart de zéro sur ce téléphone. Ce bouton n’apparaît qu’en cas de connexion avec Google. Si vous avez joué en invité, aucune donnée vous concernant n’est enregistrée sur nos serveurs ; il suffit de désinstaller le jeu pour supprimer la sauvegarde de votre téléphone.

Avec le formulaire web

Si vous avez désinstallé le jeu ou ne pouvez pas l’ouvrir :

  1. Remplissez le formulaire ci-dessous avec l’adresse e-mail du compte Google utilisé pour vous connecter au jeu.
  2. Nous vous enverrons un e-mail pour vérifier que la demande provient bien de cette adresse ; répondez-y.
  3. Après vérification, la suppression est effectuée dans un délai de 30 jours au plus et nous vous en informons.

Si vous ne pouvez pas utiliser le formulaire, écrivez à {{contactEmail}} en indiquant les mêmes informations.

Ce qui peut subsister pendant un certain temps : les signalements vous concernant ou effectués par vous (180 jours au maximum), les journaux d’envoi des notifications (1 jour au maximum), votre pseudo dans les cadeaux que vos amis n’ont pas encore récupérés et les enregistrements d’achats et de publicités conservés par Google. Pour les demandes faites via le formulaire web, seules votre adresse e-mail et la date de la demande sont conservées pendant 3 ans, afin de prouver que nous avons donné suite à la demande. Les fichiers de votre téléphone se trouvent uniquement sur votre appareil ; pour les supprimer, désinstallez le jeu ou allez dans Paramètres → Applications → {{name}} → Stockage → Effacer les données.
