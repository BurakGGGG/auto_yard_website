Suppression du compte et des données

Cette page concerne les demandes de suppression de compte et de données pour le jeu {{name}} (Android, développeur : {{developerName}}).

Dans le jeu (immédiat)

  1. Touchez votre avatar en haut à gauche, puis ouvrez la plaque COMPTE sur l’écran PROFIL. (PARAMÈTRES → COMPTE ET CONFIDENTIALITÉ → COMPTE DE JEU mène au même endroit.)
  2. Touchez SUPPRIMER MON COMPTE, puis OUI, SUPPRIMER DÉFINITIVEMENT.
  3. Sélectionnez une nouvelle fois le compte utilisé pour vous connecter (Google ou Facebook) afin de confirmer votre identité ; si vous vous êtes connecté avec un code e-mail, saisissez le nouveau code reçu par e-mail.

Votre compte et toutes les données du tableau ci-dessous sont supprimés immédiatement, et le jeu repart de zéro sur ce téléphone. Ce bouton n’apparaît que si vous êtes connecté (avec Google, Facebook ou e-mail). Si vous avez joué en invité, aucune donnée vous concernant n’est enregistrée sur nos serveurs ; il suffit de désinstaller le jeu pour supprimer la sauvegarde de votre téléphone.

Si vous vous êtes connecté avec Facebook

La suppression de votre compte dans le jeu ou via le formulaire web ci-dessous supprime aussi toutes les données arrivées dans le jeu par la connexion Facebook : votre nom, votre adresse e-mail, l’adresse de votre photo de profil et l’identifiant Facebook associé à votre compte de jeu. Pour retirer également l’accès d’Auto Yard à votre compte Facebook, ouvrez dans Facebook Paramètres et confidentialité → Paramètres → Applications et sites web, trouvez Auto Yard et touchez Supprimer (le nom des menus peut varier légèrement selon la version de Facebook). Retirer l’accès ne supprime pas à lui seul votre progression dans le jeu ; pour cela, suivez les étapes ci-dessus.

Avec le formulaire web

Si vous avez désinstallé le jeu ou ne pouvez pas l’ouvrir :

  1. Remplissez le formulaire ci-dessous avec l’adresse e-mail du compte utilisé pour vous connecter au jeu (Google, Facebook ou connexion par e-mail). Si votre compte Facebook n’a pas d’adresse e-mail, indiquez votre nom Facebook dans le champ de note.
  2. Nous vous enverrons un e-mail pour vérifier que la demande provient bien de cette adresse ; répondez-y.
  3. Après vérification, la suppression est effectuée dans un délai de 30 jours au plus et nous vous en informons.

Si vous ne pouvez pas utiliser le formulaire, écrivez à {{contactEmail}} en indiquant les mêmes informations.

Ce qui peut subsister pendant un certain temps : les signalements vous concernant ou effectués par vous (180 jours au maximum), les journaux d’envoi des notifications (1 jour au maximum), les copies présentes dans les sauvegardes de la base de données (7 jours au maximum), l’enregistrement indiquant que quelqu’un est venu par une invitation sur un téléphone, lié à aucun compte (seulement l’empreinte de l’identifiant et la date ; conservé sans limite de durée pour prévenir les abus) et les enregistrements d’achats et de publicités conservés par Google. Pour les demandes faites via le formulaire web, seules votre adresse e-mail et la date de la demande sont conservées pendant 3 ans, afin de prouver que nous avons donné suite à la demande. Les fichiers de votre téléphone se trouvent uniquement sur votre appareil ; pour les supprimer, désinstallez le jeu ou allez dans Paramètres → Applications → {{name}} → Stockage → Effacer les données.
